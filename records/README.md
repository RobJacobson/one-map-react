# API research and evidence

[support-matrix.json](support-matrix.json) and [evidence/tf10-release.json](evidence/tf10-release.json) own current candidate versions, patch paths, routine checks and open release gates. The [grouped Markdown checklist](../docs/api-coverage.md) owns current coverage contracts, exceptions and open work, separately from runtime verification. [TF10 native style sources](evidence/tf10-native-style-sources.json) preserves compact exact-tag source identities for native unsupported boundaries.

The [facade simplification evidence](evidence/facade-simplification.json) records the compiler configuration, unchanged public contracts, routine outcomes, frozen archive, and proposed acceptance scope. Renderer acceptance for that archive remains unrun and requires separate permission.

The [independent simplification audit](evidence/facade-simplification-audit.json) records two creation-validation regressions, reproduced routine checks, compiler output verification and prioritized consolidation recommendations.

The [creation-validation repair evidence](evidence/facade-simplification-repair.json) records the corrected behavior, consolidation, lossless inventory migration and routine checks against the repaired archive. Renderer acceptance remains unverified; no commit or publication is recorded.

Records produced for the implementation retired during TF01 remain useful for upstream API inventory, versioned sources, discovered incompatibilities, and provenance. Their stage assignments, implementation mappings, artifact hashes, and runtime results apply to that implementation only.

The frozen [web](inventory-inputs/web.json), [RNMapbox](inventory-inputs/rnmapbox.json), and [MapLibre React Native](inventory-inputs/maplibre-native.json) snapshots preserve 12,131 original upstream research entries and their notes without modification. [Release endpoint additions](inventory-inputs/release-additions.json) preserve the 20 later researched declarations, including primary source links and signatures. These inputs are historical research, not live implementation or verification ledgers. Update the grouped checklist when contracts change; do not rebuild per-field status tooling. `version-baseline.json` and `tooling-baseline.json` record historical versions, not the current supported development or renderer matrix. `stage-status.json` and `evidence/` preserve historical outcomes; they are not active gates.

The [checklist migration evidence](evidence/coverage-checklist-migration.json) records the retired 12,151-entry ledger identity, grouping review, research preservation, storage savings and routine checks. Historical records may name `api-coverage.json`, its schema profiles, aliases, or removed checker scripts. Those references and outcomes remain attached to their original commits/artifacts; the [last ledger revision](https://github.com/RobJacobson/one-map-react/blob/cb12433fd9f1a68ef8a8fcf5eaf65e34a0c69e39/records/api-coverage.json) is recoverable through Git. No second live inventory is maintained.

Current direction and status live in the [requirements](../docs/requirements.md), [stage plan](../docs/stage-plan.md), [TF01 record](../docs/tf01-foundation.md), and [TF02 record](../docs/tf02-shared-map.md). Compact TF02 checkpoint evidence is [evidence/tf02-shared-map.json](evidence/tf02-shared-map.json). The [testing policy](../docs/testing-policy.md) governs new evidence and acceptance runs.

The [TF08 implementation evidence](evidence/tf08-implementation.json) preserves routine checkpoints and their original authorization limits. The subsequent [TF08 acceptance evidence](evidence/tf08-acceptance.json) records browser passes, native failures, artifact identity, and corrected runner results. Historical TF08 inventory mappings retain their original routine verification scope; runtime claims must use the acceptance record's exercised scenarios.
